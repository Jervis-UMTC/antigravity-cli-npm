# Provider CLI reference examples

The scripts under `examples/statusline` and `examples/title` demonstrate optional UI hooks from Google's proprietary Antigravity provider CLI. They are retained only as provider-integration reference material.

They are **not** examples of `antigyc` terminal output and must not be used as design guidance for this wrapper. Normal `antigyc` operation follows `AGENTS.md`: no status line, colors, model badges, emojis, or tool-stream chrome; only the single plain transient activity line is allowed.
